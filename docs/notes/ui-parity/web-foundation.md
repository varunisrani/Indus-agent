What it does (own words): the reference look is a two-colour scheme: one canvas colour and one
"ink" colour; every surface, rule, muted text and hover is a mix of the two. Corners are square.
Type mixes several voices: a heavy grotesque wordmark, a wide (expanded) display face for page and
card titles, a spaced uppercase sans for navigation, a book serif for titles and descriptions inside
lists and for segmented options, a typewriter mono for buttons, a code mono for data and a condensed
face for small badges. This task gives our dashboard that look as a foundation.

Inputs → outputs: a preset id (stored per browser under `indus-theme`) → `data-preset` and
`data-theme` (`indus-light`/`indus-dark`, read by the chat terminal) on `<html>` → two CSS colours →
the derived tokens below → Tailwind utilities used by every page.

Edge cases / failure modes:
- no stored preset, or an unknown one → the system light/dark preference picks Clear Blue or Deep
  Teal; the old stored values `indus-light`/`indus-dark` map onto those two;
- storage blocked → the choice lasts for the page only;
- collapsed sidebar: icons only, a fixed-position label on hover/focus (the rail scrolls, so the
  label is drawn outside it), links keep their accessible names; no clipped two-letter stubs, and
  the footer stacks instead of spilling (bug from `indus-ui-bugs.md` fixed);
- below 1,024 px the sidebar is a drawer opened from the header's menu icon.

## Tokens (for wave-52 builders)

Set per preset (`src/theme/presets.ts`): `--indus-canvas`, `--indus-ink`, root font size,
`color-scheme`. Everything else is derived in `src/index.css`. Use the Tailwind utility in the right
column (`bg-*`, `text-*`, `border-*` all work).

| Utility colour | Meaning | Value |
|---|---|---|
| `canvas` | page, cards, dialogs, menus | the preset canvas |
| `surface` | a faintly raised pane | ink 4 % |
| `wash` | code blocks, quiet fills, switch track | ink 6 % |
| `hover` | hover background | ink 8 % |
| `selected` | selected row, user message, count chip | ink 12 % |
| `overlay` | modal scrim (with `backdrop-blur`) | black 60 % in both themes (W54-W1-4) |
| `ink` | primary text, rules that matter, filled buttons | the preset ink |
| `ink-muted` | secondary text, labels | ink 80 % |
| `ink-soft` | hints, descriptions, idle icons | ink 62 % |
| `ink-faint` | placeholders, dotted leaders | ink 42 % |
| `on-ink` | text on an ink fill | the canvas |
| `line` / `line-strong` | 1 px borders / stronger borders and popovers | ink 15 % / 22 % |
| `success` `warning` `danger` `info` | status | green, amber, red, blue (darker on light, except the amber: `#ffbd38` in both, D-16.1207) |
| `success-wash` `warning-wash` `danger-wash` `info-wash` | tinted fills (assistant/tool messages, badges) | status 10–12 % |
| `series-input` / `series-output` | chart series (Analytics, Models) | ink / green on dark; navy / ink on light |

Older names still mapped for pages not yet rebuilt (do not use in new code): `bg`, `raised`, `fg`,
`muted`, `accent`, `accent-fg`, `ok`, `warn`, `code`, `focus`.

Fonts: `font-sans` (Archivo), `font-display` (Archivo; add `[font-stretch:125%]`), `font-serif`
(EB Garamond), `font-mono` (JetBrains Mono), `font-typewriter` (Courier Prime).

Type roles (utilities; prefer these over hand-set tracking):

| Utility | Use |
|---|---|
| `type-wordmark` | sidebar "INDUS / AGENT" |
| `type-page-title` | header page title (set by the shell) |
| `type-section-title` | card/section/dialog titles, wide uppercase ("RECENT SESSIONS") |
| `type-heading` | smaller spaced heading ("Host", "Gateway" style) |
| `type-nav` | sidebar labels, rail tooltips |
| `type-button` | typewriter buttons and select-buttons |
| `type-serif` | list titles, descriptions, segmented options |
| `type-label` | uppercase serif field label ("PROFILE", "NAME (OPTIONAL)", "SECTIONS") |
| `type-badge` | condensed small tags |
| `type-data` | ids, model names, paths, inputs |
| `type-stat` | stat values |

Layout: sidebar 15 rem (3.25 rem collapsed); header 3.25 rem with a 1 px `line` rule; page padding
`px-[1.4375rem] py-[1.4375rem]` with `gap-4` between blocks; square corners everywhere; no shadows
except popovers/dialogs/toasts. Keyframes: `indus-fade-in`, `indus-pop-in`, `indus-slide-in`.

## Components (for wave-52 builders)

Shell (`src/shell/`, `src/theme/`):
- `PageHeader` (set up by `App`): title from the route. `HeaderAfterTitle` renders right after the
  title (count chips, range buttons, a refresh icon, filter badges, switches); `HeaderActions`
  renders at the right end (page actions). Both are portals.
- `Sidebar`: wordmark + collapse button, `ProfileSwitcher` (only with more than one profile), nav
  items with icons (`NAV_ICONS`; plugin tabs get a puzzle piece), the Documentation link, footer
  (`StatusStrip`, plugin `sidebar` slot, `ConsoleEntry` "Admin console", auth widget), the theme row
  (`ThemeMenu` + `LanguageMenu`), the version row (`VersionLine`).
- `ThemeProvider` / `useTheme()` (`preset`, `choose(id)`), `ThemeMenu` (role `menu`, items
  `menuitemradio` with `data-preset`), `LanguageMenu` ("EN", English only).
- `ToastProvider` / `useToast().show(message, "info" | "success" | "error")`: square toast with a
  tone stripe, bottom right.
- `ProfileBanner`, `PressureBanner`: unchanged behaviour, new colours.

Controls (`src/ui/controls.tsx` unless noted):
- `Button` — `tone`: `default` (outlined typewriter, the usual action), `primary` (ink fill),
  `danger` (red fill), `ghost`; `size`: `sm` | `md` | `lg` (dialog footers); `icon` (a lucide
  element). `IconButton` — square icon-only, `label` is the name and tooltip, `tone="danger"` for
  delete.
- `Badge` — condensed tag; `tone`: `neutral` | `ok` | `warn` | `danger` | `accent`; optional `icon`.
  `CountChip` — the boxed number after a page title.
- `Segmented` — joined buttons in one bordered strip, picked one filled with ink (`aria-pressed`);
  `Tabs` — the same look with `role="tablist"`.
- `Field` (label + control + hint), `Input`, `Textarea`, `Select` (field look + chevron),
  `SelectButton` (a select dressed as an outlined typewriter button with a leading icon, e.g. "Any
  chat source"), `Checkbox` (square), `inputClass` for hand-built elements.
- `Switch` (`src/ui/Switch.tsx`) — square track, square thumb that fills with ink when on.
- `Card` (`padded` on by default) + `CardHeader` (icon, wide uppercase title, `aside`).
- `ListRow` — bordered row with an `aside` for badges/actions.
- `StatStrip` — figures in a bordered strip, value over label, `tone` per item.
- `LeaderStatList` — value · dotted leader · spaced uppercase label (Analytics summary style).
- `FactGrid` — label/value grid (System host facts).
- `tableClass`, `thClass`, `tdClass` — table look (serif small headers, rules between rows).
- States: `Loading`, `EmptyState` (icon + one line, optional action), `ErrorState` (red notice with
  details and a Retry button), `Notice` (neutral/warn/danger), and `QueryState` wrapping all four
  (`loading`, `error`, `empty`, `emptyText`, `emptyIcon`, `onRetry` → shows `ErrorState`).
- Dialogs (`src/ui/Dialog.tsx`): `Modal` — also exported as `PanelModal`, the role the specs name:
  square, 1 px border, wide uppercase title, serif description, close cross, blurred scrim;
  `size` `sm` | `md` | `lg`. `DialogActions` (bottom-right button row), `ConfirmDialog`.
- `cx(...)` (`src/ui/cx.ts`) joins class names; `useDismiss` (`src/ui/useDismiss.ts`) closes a
  popover on Escape or an outside press.
