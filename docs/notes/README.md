# Task notes

Every task gets a note here **before** any code is written: `docs/notes/<phase>/<slug>.md`, for
example `docs/notes/P00/scaffold.md`. Start from [`_template.md`](_template.md).

A note turns what you read into your own words, and it is the record of what you read. Everything
above the compare checklist is written first; the checklist is filled in after the rewrite, when the
reference is reopened to look for gaps. The PR for the task names the note on its `Task note:` line.

Never paste or paraphrase line by line from the reference into a note. Reference names may appear
here (this is `docs/`), but describe behaviour, not the reference's text.
