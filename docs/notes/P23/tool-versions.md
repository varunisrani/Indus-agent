# P23 third-party tool and format versions (interop record)

Each pinned version P23 relies on, where the pin lives and how it was checked. Names and flags were
checked against each tool's own documentation or `--help` at that version, never against the
reference. Merged at integration (wave 36) from the five slices' sections; "verified" means checked
against upstream over the network at integration (2026-10-21), "unverified" means still owed.
