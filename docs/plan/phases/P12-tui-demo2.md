# P12 · TUI → Demo 2

**Weeks:** 3 (plus frontend-track prework from week 7, see "Prework" below) · **Track:** F (+B bridge) · **Depends on:** P06 (classic CLI, slash registry, launcher flags), P04 (`SessionService`, `indus.protocol` + TS codegen into `packages/protocol`, error-code table), P05 (approvals, `terminal` guards used by `shell.exec`), P00 (pnpm workspace, `@indus/ui` tokens, Biome, vitest) · **Status:** planned

## Goal

`indus --tui` opens a full-screen terminal UI written in TypeScript on React 19 and upstream Ink
(D-04.2, D-16.28). The renderer spawns `indus tui-bridge --stdio` as a Python child and talks NDJSON
JSON-RPC 2.0 over its stdin/stdout (P1, D-16.10). The user can stream a reply, watch the tool trail,
answer approval/clarify/sudo/secret cards, switch model and session, queue or steer while busy, and
interrupt with the Ctrl+C priority order. Killing the Python child mid-turn reopens the same stored
session without resubmitting anything; a resize storm does not tear. It proves that the declared
contract and `@indus/client` (shared later by web and desktop) hold up against a real front end.

**Prework (frontend track, weeks 7–17, mock data only).** Tasks P12-01 to P12-06 and the
renderer tasks P12-07 to P12-27 can start before P06 lands. They run against the fake server in
`packages/client/src/testing/` and the recorded event streams of P12-06, and against the generated
types in `packages/protocol` (stub them by hand only until P04's generator exists; the stub file is
deleted when the generator lands). P12-01 is the **D-04.2 upstream Ink spike** and must finish before
any renderer task commits to Ink APIs. The backend tasks P12-28 to P12-32 and the E2E task P12-33
start once P06 is green.
