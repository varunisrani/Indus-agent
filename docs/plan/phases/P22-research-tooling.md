# P22 · Research tooling

**Weeks:** 20–21 (1 week of builder time; any slot after P10) · **Track:** B · **Depends on:** P10 (tools, delegation, toolsets), P21-14 only for per-task container images (optional; without it the batch runner refuses rows that name an image) · **Status:** planned

## Goal
A researcher can turn the agent into a data engine: `indus research batch` runs a JSONL of prompts
through a process pool of in-process agents with randomly sampled toolsets, writes every finished
sample durably before counting it, and resumes after a kill without paying twice. The dataset is
bound to its checkpoint by hash, so editing the dataset under the same run name can never silently
skip rows (D-16.31, R10.3). One shared converter writes our own documented trajectory JSONL format
(D-16.59), used by the batch runner, the interactive `--save-trajectories` saver and the single-tool
SWE runner alike (R10.7). `indus research compress` squeezes trajectories under a token budget with
a tokenizer that never runs remote code unless asked (D-16.21, D-16.60), and writes a rejects file
instead of silently dropping timed-out samples (R10.8). A small eval-harness kit gives future A/B
experiments one shape: one-variable arms, oracle scoring, resume-safe results, never on live data.

Interop note: the trajectory turn shape (`conversations` of `{from, value}` with `from` in
`system | human | gpt | tool`) and the tags `<tools>`, `<tool_call>`, `<tool_response>`, `<think>`
are an open convention used by several open-weight model families; check them against a public
description of that convention, not against the reference. Hugging Face `transformers`
(`AutoTokenizer.from_pretrained`, `trust_remote_code`, `revision`) and `datasets` are third-party
APIs: pin them in a new `research` extra (D-16.52) and check names against their docs at that pin.
The format is ours and is documented in `docs/user/reference/trajectory-format.md`; we promise no
byte-equality with the reference (D-16.59). The reference's own scratchpad tag is a reference name
and is not recognised.
