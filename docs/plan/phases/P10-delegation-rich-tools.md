# P10 · Delegation and rich tools

**Weeks:** 2 · **Track:** B (backend, Python) · **Depends on:** P09 (review-fork machinery reused by side questions; skills/memory blocked in children), P08 (the auxiliary model client P08-17 — every side task here (vision fallback, snapshot summaries, goal/loop judges, side questions, MoA references) calls it; no new client is built — plus fallback and usage), P05 (terminal, file and web tools, approvals, env builder, SSRF policy, process registry), P04 (turn loop, inline tool table, `SessionService` event injection), P11 for P10-07 only (worktree module; P11 runs in parallel with P08–P09 and lands first) · **Status:** planned

## Goal
The agent can hand work to subagents (a synchronous batch, then background children it can list,
steer and stop), write Python that calls its own tools (`execute_code`, per-call script then a
persistent kernel), drive a headless Chromium, look at images, generate images and video through
providers, speak and listen (TTS, STT and CLI voice mode), control a desktop in the background, run
mixture-of-agents turns, answer side questions without touching the conversation, and keep working
on a goal, a loop or a heartbeat. This proves the M2 demo item "a subagent batch" and finishes the
tool catalogue parity for 1.0 except the platform-specific tools (P15/P16) and the P3 browser
backends listed below.

Not in this phase: cloud browser providers, Camofox/Lightpanda engines, real-profile mode,
`browser_exec`, `browser_vault` and private-URL routing (C22, C24, C25: P3; proposed for P24, see
cross-phase issues); TUI voice push-to-talk and wake word (J22, P12/P24); desktop voice (P20).

Interop note: Playwright (Python) and the Chrome DevTools Protocol method names (`browser_cdp`) are
third-party APIs; check each call against Playwright's API reference and the CDP protocol viewer for
the pinned Playwright and Chromium versions in `uv.lock`. Provider HTTP shapes for image, video, TTS
and STT backends (OpenAI images/audio, Groq audio) are checked against each vendor's published API
reference at the date pinned in the task note. Read the reference only for behaviour and edge cases.
