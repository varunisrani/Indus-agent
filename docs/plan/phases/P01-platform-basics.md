# P01 · Platform basics

**Weeks:** 2–3 (1.5 weeks) · **Track:** B (Python) · **Depends on:** P00 (layers, fakes, `FakeClock`, pins) · **Status:** planned

## Goal
Everything the runtime needs before it can open a store or call a model: knowing the machine
(`indus.platform`), knowing which profile and home this process serves before any app module is
imported, a `Scope` value that carries that answer everywhere, a config file that loads with
defaults, survives a broken edit, and saves without losing comments or writing defaults, a `.env`
file and an OS-keychain `SecretStore` that keep secrets out of config, redacted queue-based logs
routed per profile, and an injectable clock in the configured time zone. When it is done, a test
can build a `Scope` for a temp profile, read and write config and secrets through it, and every
log line it produces lands in that profile's files with secrets masked.
