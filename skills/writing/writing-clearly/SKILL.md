# Writing clearly

Clear writing puts the reader's question first and answers it in as few plain words as the subject
allows. Use this skill when you write for the user and when you edit what they wrote.

## When to use

- The user asks you to edit, shorten, rewrite or "polish" a text.
- You are drafting something other people will read: an email, a README, release notes, a report.
- A text is meant for a specific audience or tone (a customer, an executive, a beginner).

## Procedure

1. **Settle the brief.** Who reads it, what should they know or do afterwards, and how formal it
   should be. If the user did not say and it matters, ask once with `clarify`.
2. **Find the main point** and put it first: in the opening line of an email, the first paragraph
   of a report, the first bullet of a summary.
3. **Cut.** Remove words that do no work: "in order to" → "to", "at this point in time" → "now",
   throat-clearing openers, repeated ideas, hedges stacked on hedges.
4. **Prefer the plain word and the active voice.** "We fixed the bug" beats "the bug was
   addressed". Replace jargon unless the reader uses it daily.
5. **Shape it for scanning.** Short paragraphs, one idea each. Headings for documents longer than
   a screen. Lists for steps or parallel items, not for every sentence.
6. **Match the tone.** Warm but direct for colleagues; precise and calm for bad news; no hype in
   technical writing. Keep the author's voice when you edit their text.
7. **Check facts and names.** Numbers, dates, product and people's names must survive the edit
   unchanged unless the user asked you to correct them.
8. **Deliver.** Give the edited text, then, if helpful, a short note on the main changes. For long
   files, edit in place with `patch` so the user can see the diff.

## Pitfalls

- Changing the meaning while improving the style. Re-read each edited sentence against the
  original.
- Over-cutting until the text turns curt or loses needed context.
- Inventing details (figures, quotes, dates) to make the text feel complete.
- Uniform "corporate" tone that flattens a personal message.
- Marking every change in a long text; summarise the kinds of change instead.

## Verification

- The main point appears in the first two sentences.
- Every fact, number and name from the original is still there and still correct.
- The text is shorter, or every added word earns its place.
- Read aloud, no sentence makes you stop and re-read.
